L'engagement sur Prof Chez Vous

Qu’est-ce qu’un engagement sur Prof Chez Vous ?

Un engagement est la manière officielle de collaborer avec un professeur sur Prof Chez Vous. Il permet de formaliser clairement les attentes entre le parent ou l’apprenant et le professeur avant le début des cours.

{% if abonnement.type_abonnement == 'STANDARD' or abonnement.type_abonnement == TypeAbonnement.STANDARD %}

La proposition d’un engagement

La première étape consiste à choisir un professeur. Vous pouvez effectuer cette recherche directement sur la page de recherche, où sont listés les professeurs vérifiés correspondant à vos besoins.

Vous pouvez également sélectionner un professeur depuis votre espace personnel. En cliquant sur « Voir le profil », vous accédez à son profil public, puis vous pouvez initier la collaboration via le bouton « Contacter ce professeur ».

Vous remplissez alors un formulaire structuré précisant notamment :
– la matière
– le niveau
– les disponibilités
– les objectifs attendus

👉 Selon votre plan, la proposition d’un engagement est toujours gratuite.
Aucun paiement n’est demandé au moment de l’envoi.

– En Plan Standard, un frais unique de {{ DEFAULT_ENGAGEMENT_PRICE }} {{ DEFAULT_CURRENCY }} est demandé uniquement après confirmation du professeur, pour activer l’engagement et débloquer l’accès complet à la collaboration :
* messagerie sécurisée
* planification des séances
* journal de suivi pédagogique (pour les parents)
